### Протокол WebSocket

```
📤 Клиент → Сервер:
  { type: 'servo',     board: 'head'|'body', servo: 'eyeL', angle: 90 }
  { type: 'rgb',       r: 255, g: 128, b: 0 }
  { type: 'preset',    name: 'red' }
  { type: 'animation', name: 'wave', params: { speed: 1.0 } }
  { type: 'cmd',       data: 'HOME'|'CENTER'|'STATUS'|'OFF' }

📥 Сервер → Клиент:
  { type: 'state',          data: { servos, rgb, animation }, connections: { uno, mega } }
  { type: 'server_status',  data: { uptime, memory, networks, components } }
  { type: 'sensor',         data: { voltage, temperature } }
  { type: 'firmware',       data: { status: 'checking'|'downloading'|'flashing'|'done' } }
  { type: 'log',            data: { level: 'info'|'warn'|'error', msg: '...' } }
  { type: 'camera',         data: { status: 'on'|'off', fps: 15 } }
```

### REST API

```
GET    /api/status              — полное состояние системы
GET    /api/server/status       — uptime, memory, network, компоненты
GET    /api/logs                — лог-буфер
GET    /api/camera/status       — статус камеры
POST   /api/camera/start        — запустить стрим
POST   /api/camera/stop         — остановить стрим

PUT    /api/servo               — установить серво
POST   /api/rgb                 — установить RGB
POST   /api/rgb/off             — выключить
POST   /api/rgb/preset          — пресет цвета

POST   /api/animation           — запустить анимацию
POST   /api/animation/stop      — стоп

POST   /api/update/check        — проверить обновления
POST   /api/update/apply        — скачать и применить
POST   /api/update/flash        — прошить Arduino через arduino-cli
GET    /api/update/status       — статус обновления

GET    /api/docs                — Swagger UI
GET    /api/docs.json           — OpenAPI Spec
```

## 🚀 Функционал по слоям

### Layer 1 — Базовый (сейчас)
- [x] Подключение по WebSocket (ws/wss)
- [x] Управление серво (глаза, челюсть, плечи, локти)
- [x] RGB LED с ползунками
- [x] Пресеты цветов (10 штук)
- [x] Базовые анимации (wave, nod, blink)
- [x] Лог команд
- [x] PWA (service worker)

### Layer 2 — Доработки интерфейса
- [ ] Сворачиваемые блоки (по клику на заголовок)
- [ ] При подключении — свернуть блок подключения
- [ ] Если нет связи — блоки управления заблокированы
- [ ] Автоподключение при заходе на страницу
- [ ] Исправить порядок RGB (красный/синий)
- [ ] Мигание с настраиваемым таймингом (горит/не горит)
- [ ] Отдельный тумблер мигания (не сбрасывает цвет)
- [ ] Плавный переход между цветами (от → к)

### Layer 3 — Системный монитор
- [ ] uptime Pi
- [ ] CPU, RAM, SD
- [ ] Сеть: интерфейсы, IP, статус
- [ ] Напряжение плат (UNO, MEGA)
- [ ] Статус компонентов (серво, RGB, камера, Kinect)

### Layer 4 — Автообновление
- [ ] Сервер проверяет GitHub releases при старте
- [ ] UI панель с проверкой и применением
- [ ] **Самообновление сервера**: скачать ZIP → распаковать → перезапустить
- [ ] **Прошивка Arduino**: arduino-cli на Pi, прошивки из релизов
- [ ] Индикация прогресса

### Layer 5 — Камера и Kinect
- [ ] MJPEG стрим с USB-камеры
- [ ] Кинопоток: глубина, RGB, скелет (если Kinect)
- [ ] Включение/выключение из UI

### Layer 6 — Продвинутые фичи
- [ ] **Запись/воспроизведение движений** — записать последовательность серво, сохранить как позу/анимацию
- [ ] **Геймпад** (Gamepad API) — управление серво с джойстика
- [ ] **Голосовое управление** — Web Speech API → команды
- [ ] **Speech Synthesis** — Pi говорит (через TTS)
- [ ] **Распознавание лиц** — PiCamera + OpenCV слежение
- [ ] **Пресеты поз** — полные позы робота (серво + RGB)
- [ ] **Макросы** — кнопки на несколько действий
