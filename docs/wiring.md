# Robot Catty — Wiring Documentation

Полное описание подключения Robot Catty.

## Общая схема

```
┌──────────────────────────────────────────────────────────────┐
│                   5V / 14A  БЛОК ПИТАНИЯ                     │
│                        │        │                            │
│     ┌──────────────────┤        ├──────────────────┐         │
│     │                  │        │                  │         │
│     ▼                  │        │                  ▼         │
│  ┌───────┐             │        │             ┌────────┐    │
│  │  Pi   │◄────USB─────┤        │             │ Servo  │    │
│  │  3B   │   Uno       │        │             │ #1-7   │    │
│  │       │◄────USB─────┤        │             │ (VCC)  │    │
│  │       │   Mega      │        │             └──┬─────┘    │
│  │ GPIO  │             │        │                │          │
│  │ 5V Pin│◄────────────┤        │                │          │
│  │ GND   │◄────────────┴────────┴────────────────┘          │
│  └───┬───┘                                                   │
│      │ PWM сигналы (только сигнал!)                          │
│      ├── D4 ── eyeLR  ├── D2 ── shoulderL                    │
│      ├── D7 ── eyeUD  ├── D3 ── shoulderR                    │
│      ├── D8 ── jaw    ├── D4 ── elbowL                       │
│      │                ├── D5 ── elbowR                       │
└──────────────────────────────────────────────────────────────┘
```

> ⚠️ **Главное правило**: VCC (+5V) и GND сервоприводов — НАПРЯМУЮ к блоку питания.
> К Arduino идут только сигнальные (PWM) провода!

## Правила подключения

### Сервоприводы (3 провода каждый)

| Цвет провода | Назначение | Куда подключить |
|-------------|-----------|----------------|
| 🔴 Красный | VCC (+5V) | **Напрямую к +5V блока 14A** |
| ⚫ Чёрный/Коричневый | GND | **Напрямую к GND блока 14A** |
| 🟡 Оранжевый/Белый/Жёлтый | Сигнал (PWM) | К пину Arduino (см. таблицу ниже) |

### Raspberry Pi 3B

| GPIO (физический) | Сигнал | Куда |
|-------------------|--------|------|
| Pin #2 или #4 | 5V | К +5V блока питания |
| Pin #6, #9, #14, #39 | GND | К GND блока питания |

### Arduino Uno (Голова)

Питается по USB от Raspberry Pi. Сигналы серво:

| Пин | Провод серво | Серво | Описание |
|-----|-------------|-------|----------|
| D3 | — | RGB R | Красный светодиод (через 220Ω) |
| D5 | — | RGB G | Зелёный светодиод (через 220Ω) |
| D6 | — | RGB B | Синий светодиод (через 220Ω) |
| D4 | 🟡 к eyeLR | eyeLR | Левый/правый глаз |
| D7 | 🟡 к eyeUD | eyeUD | Глаза вверх/вниз |
| D8 | 🟡 к jaw | jaw | Челюсть |
| GND | — | RGB GND | Общий GND |

### Arduino Mega 2560 (Тело)

Питается по USB от Raspberry Pi. Сигналы серво:

| Пин | Провод серво | Серво | Описание |
|-----|-------------|-------|----------|
| D2 | 🟡 к shoulderL | shoulderL | Левое плечо |
| D3 | 🟡 к shoulderR | shoulderR | Правое плечо |
| D4 | 🟡 к elbowL | elbowL | Левый локоть |
| D5 | 🟡 к elbowR | elbowR | Правый локоть |
| D6-D9 | 🟡 (резерв) | — | Будущее расширение |

### RGB LED

4-pin RGB LED (общий катод), питается от Arduino Uno через резисторы:

| Вывод LED | Пин Uno | Резистор |
|-----------|---------|----------|
| Красный (R) | D3 (PWM) | 220Ω |
| Зелёный (G) | D5 (PWM) | 220Ω |
| Синий (B) | D6 (PWM) | 220Ω |
| Катод (GND) | GND | — |

## Общий GND (критически важно!)

Все GND должны быть соединены в одну точку:

```
GND блока 5V ─── GND Pi (GPIO) ─── GND Arduino (через USB) ─── GND серво
```

Без общего GND серво будут дёргаться, а управление — сбоить.

## Расчёт потребления

| Компонент | Средний ток | Пиковый ток |
|-----------|------------|-------------|
| Raspberry Pi 3B | ~1.0A | ~1.5A |
| Arduino Uno + Mega | ~0.15A | ~0.3A |
| 7 серво | ~2.1A | ~5.6A |
| **Итого** | **~3.5A** | **~7.5A** |

Блок 5V 14А — более чем достаточно.

## Чего НЕ делать

- ❌ **Не питать серво через Arduino 5V** — стабилизатор Arduino рассчитан на <1A
- ❌ **Не питать серво через Pi 5V** — дорожки Pi не выдержат 5A+
- ❌ **Не использовать 12V** — все компоненты 5V, 12V сожжёт и Pi, и серво
- ❌ **Не подключать VCC серво к сигнальным пинам** — сожжёшь порт Arduino
- ❌ **Не игнорировать общий GND** — без него всё будет дёргаться

## Порядок сборки

1. Подключи блок питания — **не включай**
2. Соедини **GND** всех устройств (общая шина)
3. VCC серво (+5V) → клемма **+5V блока**
4. GND серво → клемма **GND блока**
5. Сигналы серво → пины Arduino (только сигнал!)
6. Pi 5V (GPIO пин #2 или #4) → **+5V блока**
7. Pi GND (GPIO пин #6) → **GND блока**
8. Arduino Uno → USB Pi
9. Arduino Mega → USB Pi
10. RGB LED → Uno через 220Ω резисторы
11. **Включи блок питания**

## Serial протокол (9600 baud)

### Uno (Голова)

| Команда | Описание | Пример |
|---------|----------|--------|
| `SERVO:<name>:<angle>` | Установить угол серво (0-180) | `SERVO:eyeL:120` |
| `RGB:<r>,<g>,<b>` | Установить цвет (0-255) | `RGB:255,128,0` |
| `OFF` | Выключить RGB | `OFF` |
| `FADE:<r>,<g>,<b>` | Плавный переход | `FADE:0,0,255` |
| `BLINK` | Режим мигания | `BLINK` |
| `PRESET:<name>` | Готовый цвет | `PRESET:red` |
| `STATUS` | Текущее состояние | `STATUS` |

Пресеты: `red`, `green`, `blue`, `white`, `yellow`, `cyan`, `magenta`, `orange`, `pink`, `purple`

### Mega (Тело)

| Команда | Описание | Пример |
|---------|----------|--------|
| `SERVO:<name>:<angle>` | Установить угол серво (0-180) | `SERVO:shoulderL:120` |
| `CENTER` | Центрировать все серво | `CENTER` |
| `STATUS` | Текущее состояние | `STATUS` |

## Запуск

```bash
# На Raspberry Pi
cd ~/robot-catty/server
npm install
npm start

# Автозапуск через crontab
@reboot cd /path/to/robot-catty/server && npm start
```
